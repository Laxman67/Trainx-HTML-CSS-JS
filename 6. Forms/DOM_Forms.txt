********************* Forms in HTML **************

*Important: MDN Docs and W3school



What is Forms : An HTML form is used to collect user input.

<form> element is used to create an HTML form for user input:
 <input> element is the most used form element.



<input type="text">	Displays a single-line text input field
<input type="number">	Displays a single-line number input field
<input type="textarea">	Displays a multi-line  texts input field
<input type="email">	Displays a single-line email input field and provide validation
<input type="password">	Displays a  text  input for password
<input type="date">	Input for Date
<input type="time">	Input for Time
<input type="range">	Input for Range
<input type="file">	Displays a single-line text input field

<input type="radio">	Displays a radio button (for selecting one of many choices)
<input type="checkbox">	Displays a checkbox (for selecting zero or more of many choices)

<input type="submit">	Displays a submit button (for submitting the form)
<input type="button">	Displays a clickable button
<select >	Displays a selectable fields
 <label for="website">Enter your website:</label>
  <input type="url" id="website" name="website" placeholder="https://example.com" required>

action = Where should the form data go after submission?
method = How should the data be sent? (get or post)


the browser sends the form data using an HTTP POST request to actionPage.html.

The issue is:

GET requests can open normal HTML pages directly.
POST requests usually need a server/backend to receive and process the data.
