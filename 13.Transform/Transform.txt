Transform Property in CSS

The transform property in CSS allows you to apply 2D or 3D transformations to elements, such as
1. rotating : rotate()
2. scaling, : scaleX() , scaleY() , scale()
3. translating them :   translateX() , translateY() , translate()



====> Rotating <=====
The rotate() CSS function defines a transformation that rotates an element around a fixed point on the 2D plane, without deforming it. Its result is a <transform-function> data type


transform: rotate(0);

transform: rotate(90deg);

transform: rotate(0.25turn);



=====> Scaling  <====
scale refers to  resizing an element in the 2D or 3D
2D = x, Y
3d =  x,y,Z


The scaleX() CSS function defines a transformation that resizes an element along the x-axis (horizontally). It

transform: scaleX(1);
transform: scaleX(0.7);
transform: scaleX(1.3);


The scaleY() CSS function defines a transformation that resizes an element along the y-axis (vertically).

transform: scaleY(1);
transform: scaleY(0.7);
transform: scaleY(1.3);



The scale() CSS function defines a transformation that resizes an element on the 2D plane.

transform: scale(1);
transform: scale(0.7);

transform: scale(1, 1.7); // x, y

=====> translating <====
In CSS, translate() is a transform function used to move (translate) an element along the X and/or Y axis without affecting the document flow.


translateX(50px) → Move only horizontally
translateY(30px) → Move only vertically
translateZ(20px) → Move along the Z-axis (3D)
translate3d(x, y, z) → Move in 3D space

Note: Does not affect surrounding elements (unlike margin or position).
